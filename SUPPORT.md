# Support

kombify Techstack Open Core is open source and in public beta. Support is
asynchronous and community-visible; there is no response-time guarantee.

| Need | Where |
| --- | --- |
| Questions, setup help, ideas | [GitHub Discussions](https://github.com/kombifyio/TechStack/discussions) |
| A reproducible bug in a released version | [Issues](https://github.com/kombifyio/TechStack/issues/new) |
| A security vulnerability | [Private security advisory](https://github.com/kombifyio/TechStack/security/advisories/new), never a public issue |
| Documentation | [docs.kombify.io](https://docs.kombify.io) |

Before you post, include the release version, how you run Techstack (Windows
client, container image, or Compose), the host operating system, and the
relevant log lines. Redact hostnames, addresses, and secrets.

Only the latest public release receives fixes. StackKits questions that do not
involve Techstack belong in the
[StackKits repository](https://github.com/kombifyio/StackKits).
