# Raster service icons

The service-card PNG files are the PNG variants published by
[homarr-labs/dashboard-icons](https://github.com/homarr-labs/dashboard-icons/tree/main/png),
retrieved on 2026-10-02. They use the same upstream as the existing bundled SVG
icons. The upstream Apache-2.0 license is retained in `LICENSE.dashboard-icons`.
`postgresql.png` is served for the PostgreSQL catalog entry; unavailable or
unrecognized vendor icons use the existing `kombify.png` generic icon.

`calagopus.svg` is the Calagopus Panel icon from
[calagopus/panel](https://github.com/calagopus/panel/blob/main/frontend/public/icon.svg)
(MIT License, Copyright (c) Calagopus, 0x7d8), retrieved on 2026-10-07.

These files are included in the normal Techstack static application deployment;
the API serves URLs on the existing `techstack.kombify.io/brand-logos/` origin.
